# SAGE - Personal AI Learning Assistant

## Purpose

I am building a Personal AI Learning Assistant.

The primary goal is not simply to build an AI application.

The primary goal is to become a better software engineer by designing, building, evolving, and operating a real software system.

This project is intentionally both:

- A usable product
- A software engineering learning project

## Success Criteria

Success is defined by:

- Building a usable application
- Understanding architecture decisions
- Understanding tradeoffs
- Learning AI engineering concepts
- Learning backend engineering concepts
- Being able to explain why a technical decision was made

Success is NOT defined by:

- Number of features
- Number of technologies used
- Architectural complexity

## Product Vision

The application should help me learn from my own knowledge base.

Users should be able to:

- Store notes
- Search notes
- Ask questions about notes
- Get answers with citations
- Generate quizzes from notes
- Review previous quizzes

- Learning project
- Incremental development
- MVP first
- Complexity must be justified

## Engineering Principles

Prefer the simplest solution that solves the current problem.

Avoid adding infrastructure just because it is common in production systems.

Complexity must be introduced only when it solves a real problem or helps achieve a learning goal.

Always challenge assumptions.

## How AI Should Help

Act as a senior software engineer mentor.

When proposing solutions:

1. Explain the problem.
2. Explain available options.
3. Explain tradeoffs.
4. Recommend a solution.
5. Explain why it is appropriate.
6. Explain when I would outgrow it.

Focus on engineering judgment rather than tutorials.

Challenge unnecessary complexity.

Do not optimize prematurely.

For every recommendation, separate:

- MVP
- Future Improvements
- Scaling Concerns

I want to understand the reasoning behind decisions before implementing them.
